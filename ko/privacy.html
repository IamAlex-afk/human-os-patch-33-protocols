개인정보 처리방침

최종 업데이트: 2026-10-20 · 법률 용어 없이 쉬운 말로 썼습니다.

요약: Mind-OS는 아무것도 수집하지 않습니다. 서버, 데이터베이스, 분석 도구, 쿠키, 추적이 없습니다. 답변은 브라우저 안에서 채점되며 기기 밖으로 나가지 않습니다.

수집하는 데이터

없습니다. Mind-OS는 정적 웹사이트로, 테스트에는 서버가 없고 어디로도 아무것도 보내지 않습니다.

답변이 저장되는 곳

답변은 페이지가 열려 있는 동안 브라우저에서 채점되며, 저장되거나 전송되지 않습니다. 사이트가 브라우저의 localStorage(사용자 기기)에 남기는 것은 선택한 언어와 언어 안내를 닫았는지 여부, 두 가지 설정뿐입니다. 오프라인에서도 쓸 수 있도록 브라우저가 사이트 자체의 파일도 저장하지만, 그 안에 사용자에 관한 정보는 없습니다. 사이트 데이터를 지우면 모두 삭제됩니다.

쿠키

어떤 종류의 쿠키도 사용하지 않습니다. 분석용, 광고용, 세션용 모두 없습니다. 설정되는 것이 없으므로 동의할 것도 없습니다.

추적 및 분석

추적 픽셀, Google Analytics, Facebook Pixel, 핑거프린팅, 제3자 추적기가 없습니다. 저희는 사용자가 누구인지, 방문했는지 알지 못합니다.

제3자 서비스

글꼴은 이 사이트에서 제공하거나 사용자 기기의 글꼴을 씁니다. 어떤 페이지도 다른 서버에서 아무것도 불러오지 않습니다. 사이트는 GitHub Pages에서 호스팅되며, 다른 호스팅과 마찬가지로 브라우저가 페이지를 요청할 때 IP 주소를 봅니다. 저희는 그 정보를 받지 않으며 로그에도 접근할 수 없습니다.

아동

Mind-OS에는 유해한 콘텐츠가 없고 데이터를 수집하지 않으므로, 미성년자를 포함해 누구에게도 데이터 위험이 없습니다. 이는 교육 목적의 자기 성찰 도구이며 의학적 조언이나 진단이 아닙니다.

사용자의 권리

저희는 사용자에 관한 데이터를 보유하지 않으므로 저희 쪽에 열람, 내보내기, 삭제를 요청할 대상이 없습니다. 데이터는 사용자의 기기에만 있으며, 사용자만 접근하거나 삭제할 수 있습니다.

직접 확인하는 방법

브라우저 개발자 도구(F12) → Network 탭을 열고 테스트를 해 보세요. 채점은 브라우저에서 실행되는 JavaScript가 하므로 다른 서버로 가는 요청은 하나도 없습니다. 소스 코드는 공개되어 있습니다.
