Politique de confidentialité

Dernière mise à jour : 2026-10-20 · En langage clair, sans jargon juridique.

En bref : Mind-OS ne collecte rien — pas de serveur, pas de base de données, pas de statistiques, pas de cookies, pas de traçage. Vos réponses sont calculées dans votre navigateur et ne quittent jamais votre appareil.

Quelles données nous collectons

Aucune. Mind-OS est un site statique : les tests n’ont pas de serveur et n’envoient rien.

Où vont vos réponses

Vos réponses sont calculées dans votre navigateur tant que la page est ouverte, et ne sont ni enregistrées ni envoyées. Le site ne conserve que deux réglages dans le localStorage de votre navigateur, sur votre appareil : la langue choisie et le fait d’avoir fermé ou non la suggestion de langue. Pour fonctionner hors ligne, le navigateur garde aussi les fichiers du site lui-même ; ils ne contiennent rien sur vous. Effacer les données du site supprime le tout.

Cookies

Nous n’utilisons aucun cookie — ni pour l’analyse, ni pour la publicité, ni pour les sessions. Il n’y a rien à accepter, puisque rien n’est déposé.

Suivi et analyse d’audience

Il n’y a ni pixel de suivi, ni Google Analytics, ni Facebook Pixel, ni empreinte numérique, ni traceur tiers. Nous ne savons pas qui vous êtes ni que vous êtes venu.

Services tiers

Les polices viennent de ce site ou de votre appareil ; aucune page ne charge quoi que ce soit depuis un autre serveur. Le site est hébergé sur GitHub Pages : comme tout hébergeur, il voit votre adresse IP quand votre navigateur demande une page. Nous n’en recevons rien et n’avons pas accès à ses journaux.

Enfants

Mind-OS ne contient aucun contenu nuisible et ne collecte aucune donnée ; il ne présente donc aucun risque pour les données de quiconque, mineurs compris. C’est un outil éducatif de réflexion, pas un avis médical ni un diagnostic.

Vos droits

Comme nous ne détenons aucune donnée vous concernant, il n’y a rien à demander, exporter ou supprimer de notre côté. Vous gardez le contrôle total : vos données se trouvent uniquement sur votre appareil, et vous seul pouvez y accéder ou les supprimer.

Comment le vérifier vous-même

Ouvrez les outils de développement du navigateur (F12) → onglet Network et faites un test : aucune requête ne part vers un autre serveur, car le calcul est fait par le JavaScript exécuté dans votre navigateur. Le code source est ouvert.

Contact

Des questions ? Ouvrez un ticket : GitHub Issues.
