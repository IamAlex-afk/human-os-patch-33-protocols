📋 Ce que mesure cette évaluation

Cet ensemble de 28 questions vous aide à observer vos habitudes d'utilisation de l'IA. Basé sur les échelles LLM-D12, AIAS et AIRD.

Pour qui : Toute personne souhaitant vérifier si son utilisation de l'IA est toujours intentionnelle. Vous obtiendrez votre Profil d'Identité IA.

Comment ça marche : Répondez à 8 questions par axe plus un test sur la peur. Tout s'exécute dans votre navigateur.

Sources : les questions sont les nôtres et s’appuient sur des recherches publiées ; ce test n’est aucune de ces échelles validées.
• LLM-D12 — Yankouskaya A., Babiker A. B., Rizvi S. W. F., Alshakhsi S., Liebherr M., Ali R. (2025). arXiv:2506.06874
• AIAS — Wang Y.-Y., Wang Y.-S. Interactive Learning Environments. doi:10.1080/10494820.2019.1674887
• AIRD — McNamara S., Thornton J. Cureus. cureus.com/articles/407877

Ceci est un outil d'auto-réflexion, pas un diagnostic médical. 100% anonyme.
